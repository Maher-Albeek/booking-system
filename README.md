Dein Projekt ist **ein Full-Stack Buchungssystem für Autos** mit **Frontend + Backend**.

Kurz beschrieben:
- **Zweck:** Nutzer können vermutlich Fahrzeuge ansehen und buchen.
- **Architektur:** Das Repo ist in **Frontend** und **Backend** getrennt.
- **Deployment:** Es gibt bereits eine öffentliche Website unter `cars-booking-system.vercel.app`.

**Genutzte Technologien:**

### Frontend
- **Angular 21.2.0**  
- **TypeScript**
- **HTML**
- **SCSS**
- **RxJS**
- **Vitest** für Tests
- **Prettier** für Code-Formatierung
- **npm** als Paketmanager
- zusätzlich `ogl` als Grafik-/WebGL-Bibliothek

### Backend
- **Java 21**
- **Spring Boot 3.5.11**
- **Spring Web** für REST APIs
- **Spring Validation** für Request-Validierung
- **Spring Security Crypto** für Verschlüsselung/Passwort-Handling
- **Springdoc OpenAPI / Swagger UI** für API-Dokumentation
- **Lombok**
- **Maven** als Build-Tool

### Projektaufbau
Aus dem Repository sieht man:
- `frontend/` → Angular-Frontend
- `src/` → Java/Spring-Backend
- `pom.xml` → Maven-Konfiguration für das Backend
- `data/` → wahrscheinlich Daten oder Seed-Dateien
- `migration-backup/` → vermutlich Backup/Migrationsdaten
